# Gold Signal Bot (Telegram)

দিনে সর্বোচ্চ ৩টা গোল্ড (XAU/USD) সিগন্যাল Telegram-এ পাঠায়।

## সেটআপ

1. Telegram-এ **@BotFather** খুলে `/newbot` দিয়ে বট বানান, **Token** কপি করুন।
2. আপনার নতুন বটকে একটা মেসেজ পাঠান, তারপর **@userinfobot** থেকে আপনার **Chat ID** জানুন।
3. GitHub রিপোতে ফাইলগুলো রাখুন:
   - `bot.py`, `requirements.txt` রিপোর রুটে
   - `signal.yml` রাখুন `.github/workflows/signal.yml` পাথে
4. রিপোর **Settings → Secrets and variables → Actions** এ যোগ করুন:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT_ID`
5. **Actions** ট্যাবে workflow চালু করুন। এরপর নিজে নিজে সোমবার-শুক্রবার চলবে, আপনার ফোনে অ্যালার্ট আসবে।

## নিউজ ও স্ট্যাটাস (news.py)

প্রতি ১০ মিনিটে চলে:
- বড় USD অর্থনৈতিক নিউজের ১ ঘণ্টা আগে সতর্কতা, আর প্রকাশের সময় "এইমাত্র প্রকাশিত" বার্তা
- গোল্ড সংক্রান্ত নতুন শিরোনাম (লিংক সহ)
- গোল্ডের বর্তমান অবস্থা: দাম, দৈনিক পরিবর্তন, ট্রেন্ড, RSI (নিউজ না থাকলে প্রতি ৩০ মিনিটে; `STATUS_EVERY_MIN` দিয়ে বদলানো যায়)

`signal.yml` এখন একটাই workflow-তে `bot.py` ও `news.py` দুটোই চালায়।

## কৌশল

- ট্রেন্ড: EMA20 ও EMA50
- এন্ট্রি: EMA20-তে পুলব্যাক ও ফিরে আসা + RSI ফিল্টার
- SL = 1.5 × ATR, TP = 3.0 × ATR (১:২)
- সেশন: ০৭:০০-১৭:০০ UTC (বাংলাদেশ সময় ১:০০ PM - ১১:০০ PM)
- সীমা: দিনে ৩টা, দুটো সিগন্যালের মাঝে কমপক্ষে ১ ঘণ্টা

`bot.py`-এর ওপরের Settings অংশে এসব বদলানো যায়।

## সতর্কতা

এটা শুধু অ্যালার্ট টুল। কোনো লাভের নিশ্চয়তা নেই। আগে ডেমো অ্যাকাউন্টে কয়েক সপ্তাহ চালিয়ে ফল দেখুন, তারপর শুধু হারালে সমস্যা নেই এমন অঙ্কে ট্রেড করুন।
